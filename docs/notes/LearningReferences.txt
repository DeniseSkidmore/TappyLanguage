Kotlin Multiplatform fits a modular monolith well. It’s one Gradle build, and module boundaries are enforced at compile time. Android is first-class, and the shared core also compiles for the web. The main alternative is Flutter: it’s a more mature single UI for both Android and web, but it’s less native on Android, and its web output draws to a canvas, which hurts accessibility. 

gh is a command-line tool for GitHub itself: pull requests, issues, CI logs, releases. The main gain is that it gives me GitHub access. I can’t click a GUI, but with gh I can open a PR, read why a CI build failed, or reply to review comments.

Markdown editor in Android Studio - Yes. It comes with a Markdown editor with a split live preview. Mermaid diagram preview is off by default; turn it on under Settings → Languages & Frameworks → Markdown.

## Installing the app
Turn on developer mode on the phone

Go to Settings → About phone and tap Build number 7 times. On Samsung it’s under About phone → Software information.
Then open Settings → System → Developer options and turn on USB debugging.

2. Connect the phone

Plug it in with a USB cable that carries data; some cheap cables only charge.
When the phone shows “Allow USB debugging?”, tick Always allow from this computer and tap Allow.
If Windows doesn’t see the phone, a Pixel needs the Google USB Driver: in Android Studio, open SDK Manager → SDK Tools and tick it. Samsung and other brands use the maker’s own USB driver.

3. Run the app

In Android Studio’s top toolbar, pick your phone in the device dropdown and the game run configuration, then press Run ▶.
Android Studio builds a debug APK, installs it and starts it.
The app stays installed afterwards, so you can open it from the launcher without the cable.
